Proyectos destacados

Estos son proyectos personales, pensados como ejercicios prácticos para aplicar HTML, CSS y JavaScript de forma progresiva.

Black Jack

Juego del black Jack implementado con HTML, CSS y JavaScript. Permite al usuario jugar contra la computadora, siguiendo las reglas básicas del juego.

Problema que resuelve: ayuda a practicar contra la maquina y mejorar la estrategia del jugador, además de ser una forma divertida de pasar el tiempo.

Tecnologías utilizadas: HTML, CSS, JavaScript.

Repositorio en GitHub

Sistema medico

Sistema de gestión para administrar pacientes y citas médicas.

Problema que resuelve: permite a los profesionales de la salud organizar y acceder a la información de sus pacientes de manera eficiente, mejorando la atención médica y reduciendo errores administrativos.

Tecnologías utilizadas: HTML, CSS, JavaScript, Django.

Repositorio en GitHub

Predicta AI

Sistema inteligente para predecir riesgos, optimizar capital y tomar desiciones empresarias basadas en casos reales, sistema centrado en mipimes

Problema que resuelve: Ayuda a las mipimes a tomar decisiones empresariales basadas en datos,

Tecnologías utilizadas: HTML, CSS, Django.

Repositorio en GitHub

Eduflex
